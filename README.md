# 🌊 Sea Trips System - Backend API

A robust, secure, and scalable multi-layered Web API designed for managing sea trips, user authentication, and seamless bookings. Developed collaboratively as a team project.
---

## 🚀 Tech Stack & Tools

- **Language & Framework:** C#, .NET, ASP.NET Core Web API
- **Architecture:** Multi-layered Architecture (Controllers, Services, Repositories, DTOs)
- **Security:** JWT (JSON Web Tokens) for Role-based Authorization, BCrypt for Password Hashing
- **Database:** SQL Server / Entity Framework Core

---

## ✨ Key Features

- 🔒 **Secure Authentication & Authorization:** Implemented BCrypt for secure password hashing and JWT-based role authorization.
- 🏗️ **Clean Architecture:** Strict separation of concerns using Data Transfer Objects (DTOs), Repository pattern, and Service layers.
- 🚢 **Trip & Booking Management:** Comprehensive endpoints for handling sea trips, schedules, and user reservations.
- 👥 **Collaborative Teamwork:** Built through shared effort, task distribution, code reviews, and continuous integration.

---

## 🏗️ Project Architecture

The project follows a clean multi-layered structure to ensure maintainability and testability:
- **API (Controllers):** Handles HTTP requests and returns responses.
- **Services:** Contains the core business logic.
- **Repositories:** Manages data access and database operations.
- **DTOs:** Secures data transfer between the client and server.
